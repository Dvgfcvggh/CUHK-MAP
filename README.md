# 中大穿梭校巴

香港中文大学校园穿梭校巴的网页原型。选一个起点和一个终点，页面会按香港时间建议乘哪一路、在哪一站上车、在哪一站下车。如果走路更合适，会直接说。

这是上课期间的静态指南，不是实时到站。班次以[香港中文大学交通处](https://transport.cuhk.edu.hk/)公布为准。

## 本地运行

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43123
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123) 或 [http://localhost:43123](http://localhost:43123)。

地图用 Leaflet 画在 OpenStreetMap 上，坐标保持 WGS84。不需要地图密钥，也没有百度 AK。点地图会设成起点或终点；点在某个校巴站 45 米以内会吸到那一站。

## 步行

乘车结果里有两段，都要先选地图再打开，不需要密钥：

- 起点 → 上车站
- 下车站 → 终点

可选 Google 地图、苹果地图、高德地图、腾讯地图、百度地图。百度链接仍是步行、地区香港、`coord_type=wgs84`。

## 怎么试一趟

1. 把「设置起点」点上，选「大学站」，或在地图上点大学站附近。
2. 再点「设置终点」，选「新亚书院」。
3. 看建议里的路线、上车站和下车站。页面顶部会写当前香港时间属于上课日白天、上课日晚间，还是假日。
4. 若建议乘车，两段步行各自先选一个地图。

上课日白天会提示核对站名。例如星期三 10:00，起点「科学馆」、终点「敬文书院（下行）」：上车站是科学馆，约 40 米外还有邵逸夫堂。

## 时间怎么选路线

时钟是 `Asia/Hong_Kong`。没有手动假日开关。

| 香港时间 | 用哪套 |
| --- | --- |
| 星期一至六，且不是公众假期，约 07:30–18:55 | 1、2、2S、3、4、8，各自只在自己的开行时段里 |
| 同一个星期一至六的 19:00–23:30 | 晚间线 N。星期六也走 N。到了这个时段才出现，不是单独开关 |
| 星期日、香港公众假期 | 假日线 H，08:20–23:20，傍晚也不另开 N |

公众假期用香港特别行政区公布的通用假期（2026 和 2027），不是中大自己的校历。普通星期六走星期一至六的路线，包括晚间线 N。只有碰上公众假期的星期六才改走 H。

转堂校巴只在星期一至五教学日、并且时钟落在班次窗口里才建议，结果里会写出这个窗口：

| 路线 | 窗口 |
| --- | --- |
| 5 转堂上行 | 09:18–17:26，每小时 18、22、26 分 |
| 6A 转堂下行 | 09:10–17:10，每小时 10 分 |
| 6B 转堂下行 | 12:20–17:20，每小时 20 分 |
| 7 转堂下行 | 08:18–17:18，每小时 00、18 分 |

例：星期三 10:22，逸夫书院（上行） → 敬文书院（下行），建议转堂校巴 5，时段写着 09:18–17:26。09:00 还没到 09:18，不建议 5。星期三 20:10，大学站 → 39区（上行），建议晚间线 N。星期六 10:50 同一趟不走 H，走星期一至六的日间线（环回线 4）。星期六 20:10 同一趟走晚间线 N。星期日或国庆日 10:50 才走假日线 H。

## 数据限制

- 不是实时车辆位置，也没有当天临时改道。页面上写着「非实时，以交通处为准」。
- 没有收费小巴（交通处的上行、下行，车费另计）。校巴是中大学生和教职员专车。
- 转堂校巴的星期六教学日短窗口没有用。普通星期六走星期一至六的路线，不开 5、6A、6B、7。
- 公众假期表收到 2027 年底。更晚的假期只会按星期日处理，除非补进列表。星期六若没被标成公众假期，仍走星期一至六的路线。
- 车站坐标来自 OpenStreetMap（2026 年 10 月）。部分上行/下行在公开地图里是同一个点。三、四苑用的是该路段巴士站，OSM 上标成伍宜孙书院上/下行。
- 步行时间按校园分区估算（山路和楼梯），不是直线距离，也不是导航实测。车程按中途站数粗算，大约每站 3 分钟。
- 比较的是直接步行，和乘车全程（走到车站、等车、坐车、下车后再走）。步行至少省 15 分钟才显示「步行更快」；有车在跑但省得更少，就建议乘车，并写上直接走要多久。等超过约 40 分钟不算有车在跑。同一地点或很短的路仍显示「走过去就好」。
- 高德、腾讯按它们的链接格式带上 WGS84 数字，没有再改成火星坐标。校园小路常常不在步行路网里。
